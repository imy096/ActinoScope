# Security policy — pre-release

The ActinoScope Beta 1 public installer is not yet available or signed.

- Do not post exploitable vulnerabilities, secrets or confidential genome data in public issues.
- Use the repository owner's GitHub contact options to arrange confidential disclosure until a dedicated security contact is published.
- Obtain installers only from official repository releases after the maintainer approves publication. Verify the release checksum or signature when provided.
- The tested launcher binds the local web interface to `127.0.0.1:8501`; it is **not** intended as a public internet-facing server.
- WSL scientific executables, reference databases and optional modules have separate installation/security responsibilities.

We will publish a version-specific support and disclosure policy before general availability.
