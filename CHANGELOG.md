- Windows native launcher for the local scientific interface.
- Isolated Python application installation from a verified wheel and offline dependency wheelhouse.
- Botanical Motion RC7.7 visual interface.

Scientific end-to-end acceptance, clean-PC test, ownership/licensing approval and official DOI remain outstanding.
