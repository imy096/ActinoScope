# Official changes and improvement requests

ActinoScope is currently a **maintainer-controlled research software project**.

- The private source repository contains internal development materials.
- This public repository is primarily for user documentation and approved binary releases.
- Users may suggest bugs and improvements through issue reporting when available, but do not receive permission to merge, upload new official binaries, or distribute modified versions under the ActinoScope name.
- No external source-code contributions are accepted at this preview stage.
- A finalized software license will distinguish the rights governing ActinoScope-owned code from independent third-party components.

The maintainer controls official version numbers, tags and releases. Local code modification cannot be made technically impossible; this policy addresses authority over **official** distributions.
