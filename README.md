# ActinoScope

**From bacterial genomes to enzymes and natural products**

ActinoScope is a local-first scientific research workspace for bacterial genome analysis, genome annotation, biosynthetic gene cluster (BGC) prediction, and evidence-based exploration of enzymes and candidate natural products.

**Release status: Private Beta 1 testing — public installer not yet available.**

The approved Botanical Motion RC7.7 graphical interface runs locally on Windows. The Beta 1 launcher, Python wheel, offline dependency installation, and GUI startup have passed local testing. A real NCBI bacterial genome was accepted and its analysis workflow was planned in dry-run mode. **A complete new Bakta → antiSMASH scientific execution has not yet been accepted**, and a clean-PC installation test is still pending.

An official public download will appear under **Releases** once the installer, licensing, scientific checks and documentation have been approved. Please do not treat development builds or unofficial copies as a public release.

## Official development and updates

This public repository provides documentation and official release information. The development source is maintained in a **separate private repository**. Only the repository owner and explicitly authorized collaborators can publish official ActinoScope changes. Public visibility does not grant write access.

**Important:** A locally installed Python program may be inspectable or modifiable by the end user. The official license and trusted release signatures—not GitHub visibility alone—govern authorized use and redistribution. No software license is granted by this README.

## Research-use notice

Predicted BGCs, annotations, candidate enzymes and metabolites are computational hypotheses and are **not experimentally confirmed discoveries**. Document the exact versions of ActinoScope, its underlying tools, their databases, and the input assemblies used in publications.
