# Support and scientific bug reports

The official public release is not yet available. For documentation errors or suggestions, use GitHub Issues when issue reporting is enabled.

When reporting a reproducible software error, include the ActinoScope version, Windows and WSL versions, CPU/memory information, enabled modules, software/database versions, and a **sanitized** error log.

**Do not post private bacterial genome datasets, unpublished research results, personal Windows paths, credentials or secret tokens in public issues.** For possible security vulnerabilities, use the guidance in [SECURITY.md](SECURITY.md).

A software bug report is not a substitute for scientific validation of a predicted enzyme or candidate metabolite.
